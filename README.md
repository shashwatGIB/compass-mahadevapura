# Compass · Cambro washing, Mahadevapura

Static client dashboard by InfinityBox (GitHub Pages, no build step).

- `index.html` the page
- `data/daily.json` one row per day: cambros washed, source, provisional flag, DC / check-in photo counts
- `data/photos.json` every photo: date, time, kind (dc / checkin / other), caption, src
- `data/meta.json` last updated time
- `photos/` site photos (max 1400 px)
